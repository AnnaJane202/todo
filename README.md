# To-Do List

Список задач на чистом HTML/CSS/JS. Данные сохраняются в `localStorage`, без бэкенда и сборки.

**Демо:** [AnnaJane202.github.io/todo](https://AnnaJane202.github.io/todo/)

## Возможности

- Добавление, редактирование (двойной клик), удаление задач
- Отметка выполненных
- Фильтры: все / активные / выполненные / просроченные
- Дедлайны с цветовой индикацией (просрочено / сегодня / скоро)
- Браузерные уведомления о просроченных задачах
- Тёмная тема (с сохранением выбора)
- Drag & drop для изменения порядка (мышь + тач)
- Адаптивная вёрстка под мобильные
- Сохранение в `localStorage` (данные не теряются при перезагрузке)

## Технологии

- Чистый JavaScript (ES2017+), без фреймворков
- `localStorage` для хранения
- Pointer Events API для drag & drop
- Notification API для уведомлений
- CSS-переменные для тем
- ARIA-атрибуты для доступности

## Запуск

Просто откройте `index.html` в браузере. Или через локальный сервер (Open Server, `python -m http.server` и т.п.).

## Структура
├── index.html — разметка
├── style.css — стили (светлая/тёмная тема, адаптив)
└── script.js — вся логика
